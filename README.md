# Diário de metas de leitura

Ideia do Projeto:

Diário de leitura que permite aos usuários registrar suas leituras diárias e estabelecer metas de leitura. A aplicação é intuitiva e fácil de usar, ajudando os usuários a acompanhar seu progresso de leitura e a motivá-los a ler mais.
