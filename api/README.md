# Diário de metas de leitura - API

Breve API REST em Node.js + TypeScript, atualmente em desenvolvimento.

## Status

Em construção — estrutura inicial implementada (controllers, use-cases, repositories, adapters, Prisma).

## Tecnologias principais

- Node.js
- TypeScript
- Express
- Prisma
- pnpm
- Vitest (testes)
- Docker Compose (opções de execução/infra)

## Estrutura

A implementação principal está em [api/src/app.ts](api/src/app.ts) e o código fonte fica em [api/src](api/src).

## Como rodar (rápido)

Instale dependências e execute em modo de desenvolvimento:

```bash
pnpm install
pnpm run dev
```

Rodar testes:

```bash
pnpm test
```
